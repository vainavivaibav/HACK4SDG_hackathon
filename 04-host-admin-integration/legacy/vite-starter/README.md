# HACK4SDG Hackathon

A real-time surplus-food availability platform that helps nearby workers discover food available at event venues, such as wedding halls.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Supabase (planned backend and database)

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL printed in the terminal.

## Project Status

Initial React + Vite starter application. Features and database integration are under development.
