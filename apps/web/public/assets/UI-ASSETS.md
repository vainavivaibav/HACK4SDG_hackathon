# Illustrative UI food assets

Created with the built-in image generation tool for the HUNGER UI redesign. Generated originals remain in the Codex generated-images library. Deployment copies are JPEG-encoded at quality 85, retaining their original 1536 × 1024 composition, and are about 280–320 KB each.

Used in both `apps/web/public/assets/` and `apps/mobile/assets/`:

- `thali-v2.jpg`: vegetarian thali illustration and hero photo.
- `pulao-v2.jpg`: vegetable pulao illustration.
- `biryani-v2.jpg`: chicken biryani illustration.

These are illustrative images, not venue or listing photographs. Both interfaces label them accordingly. Actual listing image support requires a future backend field and upload workflow.
